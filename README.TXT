
PROJECT TITLE:Banking App
PURPOSE OF PROJECT:A program where you can view and edit accounts from a txt file and then save them back to a txt file
VERSION or DATE:Final version
HOW TO START THIS PROJECT:Run a new MainSystem() after the code is compiled or run the jar release
AUTHORS:S.H.W.

What can this project do?
This release is a fully functional banking app where you can:
- view an account, 
- set someones balance, 
- create an account
- delete an account
- quit the program 
All account info is loaded from a .txt file and then written back into the .txt file when the program is quit 
So check the .txt before starting the program if you want to use the program to view accounts
